# Customer Churn Risk — ML Demo
A scikit-learn pipeline with synthetic training data, holdout metrics, and an interactive hypothetical customer score.

Run:
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```
The data and labels are synthetic. Upgrade with cross-validation, calibration, a baseline comparison, and a model card. Never use this demo to make real decisions about customers.
